# Simulation – Jannik's implementation

Motion logic for the RPM, the Pico firmware that runs it, and a simulation that checks it against
measurable acceptance criteria. Author: Jannik Greiner (simulation team).

This is one of two independent implementations in `simulation/`, so the testing team can test and
compare both; the other one lives directly in `simulation/` (`rpmcore` + MuJoCo). Both use the
team conventions from [`docs/interfaces.md`](../../docs/interfaces.md): axes `outer`/`inner`,
speeds in deg/s, pulses in µs, GP15/GP16.

**Result:** the default `clinostat` strategy brings the time-averaged gravity on the sample below
**0.003 g** after 10 minutes in every simulated run, even with ±20 % servo error. Plots in
[`results/`](results/README.md), reasoning in [`docs/adr/`](docs/adr/), API and criteria for tests
in [`docs/api.md`](docs/api.md).

## Layout

| Path | What | Runs on |
|---|---|---|
| `rpm/core/` | shared core: everything that also runs on the Pico | Pico **and** PC |
| `rpm/sim/` | simulation of the real servos, report, `rpm-sim` CLI | PC |
| `firmware/` | `main.py` (control loop), `calibrate.py`, `config.py` (pins, strategy) | Pico |
| `tests/` | pytest suite + `micropython_smoke.py` for the real MicroPython interpreter | PC |
| `results/` | latest strategy comparison (generated by `rpm-sim compare`) | – |
| `viewer/` | 3D browser viewer, plain HTML + JS; runs go to `viewer/data/` (generated) | browser |
| `docs/` | API and acceptance criteria, decisions (ADRs) | – |

One core for both sides: the simulation tests exactly the code that drives the servos, and CI runs
that core under the real MicroPython interpreter.

## Simulate on a PC

Needs [uv](https://docs.astral.sh/uv/) (it fetches Python 3.11+ and all packages).

```bash
cd simulation/jannik
uv sync
uv run rpm-sim run clinostat                  # one 10-minute run, prints the metrics
uv run rpm-sim run random_walk --speed-error 0.2 --noise 0.03
uv run rpm-sim compare                        # all strategies -> results/README.md + plots
```

## Watch it

```bash
cd simulation/jannik
uv run rpm-sim viewer                         # exports the 3 strategies once, opens the browser
uv run rpm-sim export random_walk --minutes 5 --speed-error 0.2   # another run for the viewer
```

`rpm-sim viewer` serves the repo root on <http://127.0.0.1:8000/simulation/jannik/viewer/>
(`--port` to change it) because the viewer loads the printed parts straight from
`rpm_printables/`. It replays a run on the real parts and shows, next to the machine, the gravity
direction seen by the sample (dot, trail, every direction visited), the running mean against the
target, and the residual gravity over time with the 0.01 g limit. Space plays and pauses, the arrow
keys step, clicking the chart seeks.

Each export lands in `viewer/data/` (git-ignored) and appears in the viewer's dropdown. The JSON
format is documented in [`rpm/sim/export.py`](rpm/sim/export.py). The viewer needs internet access
once for three.js (pinned 0.160.0 from jsDelivr). The gears' positions along their axes are
approximate, the STLs do not fix them ([PLAN.md 2.3](../../docs/PLAN.md)).

## Checks

```bash
cd simulation/jannik && uv sync
uv run pytest                    # unit tests + acceptance criteria in simulation (~4 s)
uv run ruff check . && uv run ruff format --check .
uv run mypy
MICROPYPATH=.:firmware:tests/fake_pico micropython tests/micropython_smoke.py
```

CI runs all of them on every PR that touches `simulation/jannik/`
([workflow](../../.github/workflows/simulation-jannik.yml)).

## Run on the machine

1. Flash MicroPython on the Pico once: hold BOOTSEL, plug in USB, copy the
   [RP2040 `.uf2`](https://micropython.org/download/RPI_PICO/) to the drive that appears.
2. Check the pins in `firmware/config.py` against the wiring (`docs/interfaces.md`, "Wiring").
3. Copy the code (`uvx mpremote` or `pip install mpremote`):

   ```bash
   cd simulation/jannik
   mpremote mkdir :rpm ; mpremote mkdir :rpm/core
   mpremote cp rpm/__init__.py :rpm/
   mpremote cp rpm/core/*.py :rpm/core/
   mpremote cp firmware/config.py firmware/main.py firmware/calibrate.py :
   mpremote reset                       # main.py starts on its own
   ```

4. Recommended once per machine: `mpremote repl`, then `import calibrate`, and time one
   revolution per pulse width with a stopwatch. It writes `calibration.json` on the Pico
   (format in [`docs/api.md`](docs/api.md#calibration-file)).

Stop with Ctrl-C in `mpremote repl`; the servos always stop on exit. The Pico prints its
*estimated* residual gravity every 10 s.

## Strategies

| Name | Motion | Use |
|---|---|---|
| `clinostat` | outer 120 deg/s, inner 0.382 × that, constant | default |
| `random_walk` | random speed and direction per axis, ramped | comparison |
| `random_setpoints` | original Core Electronics behaviour | baseline |

Why the clinostat wins and why coverage is not uniform:
[ADR 0002](docs/adr/0002-clinostat-default-strategy.md).
