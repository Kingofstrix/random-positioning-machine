        DHBW Ravensburg · student project
        
Grow plants and cells almost as if in space

        
A small machine that keeps turning a sample, so gravity can't pull it the same way for long.

      

      

      
The drawing shows the planned machine. The real one may look a little different.

More about the machine: see the tab The machine.

  





  
Gravity levels

  
Weightless: the machine turns the sample so the pull of gravity evens out to almost nothing, like in space.

  
Moon and Mars need a different way of turning. The software team will add them later.

  





  
Results

  
Every time you press Start, a new row appears. Type your sample name and notes, for example what you saw.

  
Runs without a machine are marked "practice". Measurements from the machine will be added here once the teams decide what the machine measures.

  
The list is saved only in this browser on this computer, so export it after each experiment.
